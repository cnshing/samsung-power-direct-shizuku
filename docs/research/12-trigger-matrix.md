# 트리거 매트릭스 — 무엇이 `pass_through` 를 지우는가

측정일: 2026-08-30 · `tools/trigger-matrix.sh` · 잠금화면 켠 채로 (실제 사용 조건)

## 결론

```
com.samsung.android.game.gametools 는
"인식된 게임의 포그라운드 전이" 에만 pass_through 를 쓴다.

    게임이 포그라운드를 얻음  →  pass_through := 1
    게임이 포그라운드를 잃음  →  pass_through := 0
    그 외 모든 전이           →  건드리지 않는다
```

**게임을 쓰지 않는 동안에는 우리가 쓴 값을 덮을 주체가 존재하지 않는다.**

## 팔 2 — `gametools` 살아있는 상태 (pid 32461)

Roblox 를 15초 띄웠다 홈으로 나온 뒤 같은 전이를 반복. `gametools` 는 끝까지 살아있었다.

그럼에도 0~9번이 전부 유지라는 것은 `gametools` 가 살아있어도 게임 전이에만 반응함을 뜻한다.

## 부수 확인

- **잠금화면의 등장/해제는 값을 지우지 않는다** (팔 2의 1~3번, `lock=true` 실측).
- `com.roblox.client` 는 인식된 게임이다 (`gametools` 기동 + pt→1).
- `gametools` 는 게임 세션이 끝나도 한동안 살아있는다 (팔 2 내내 pid 유지).
  하지만 살아있는 것만으로는 아무 일도 하지 않는다.
- 팔 1 시작 시점에는 `gametools` 가 죽어 있었다 — 세션 종료 후 언젠가는 종료된다.

## 앱 설계 결론

재적용이 필요한 시점은 **둘뿐**이다:

| 시점 | 이유 |
|---|---|
| **재부팅 후** | 부팅 시 값이 0으로 초기화된다 ([09](09-final-results.md)) |
| **게임 세션 종료 후** | 게임이 포그라운드를 잃을 때 0이 써진다 |

**`ACTION_SCREEN_ON` 재적용은 불필요하다.** 화면 껐다 켜기는 값에 영향이 없다.
앱 전환·홈·최근앱·알림창도 마찬가지다.
