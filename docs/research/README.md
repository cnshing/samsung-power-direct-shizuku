# samsung-power-direct

Galaxy 태블릿의 **"게임 중 USB PD 충전 일시정지"(우회충전)** 를 게임이 아닐 때도 상시로 쓰기 위한 조사.

조사일: 2026-08-29 · 대상: Galaxy Tab S9+ / Android 16 (One UI 8)

## 결론부터

**검증 완료. 게임 없이 ADB 한 줄로 진짜 배터리 바이패스가 걸린다.**

```sh
adb shell settings put system pass_through 1
```

Galaxy Tab S9+ / One UI 8 실측 ([09](09-final-results.md)):

| 조건 | 부하 | `pass_through` | 배터리 전류 |
|---|---|---|---|
| 충전 중 | 유휴 (792 mA) | 0 | **+4600 mA** |
| 충전 중 | 유휴 | **1** | **−16 mA** |
| 충전 중 | 8코어 포화 (1527 mA) | 0 | **+3846 mA** |
| 충전 중 | 8코어 포화 | **1** | **+98 mA** (95초 적분 정확히 0) |

시스템이 1527 mA를 먹는데 배터리는 0 → **충전기가 부하 전량을 직접 공급한다.**
"충전만 멈추고 배터리가 시스템을 먹이는" 경우였다면 −1527 mA가 나왔어야 한다.

부수 사실:

1. **게임런처 등록도, Game Booster+ 재분류도 필요 없다.** 포그라운드가 게임 아닌 앱(Termux)이어도
   걸린다. `pass_through`가 이 기능의 유일한 입력이다.
   logcat으로 체인도 확인됐다 ([11](11-write-path.md)):
   `game.gametools` → `Settings.System.pass_through` → `BatteryService` →
   `/sys/class/power_supply/battery/pass_through`. **중간에 포그라운드 검사가 없다.**
2. **게임 부스터는 이 값을 폴링하지 않는다.** *인식된 게임의 포그라운드 전이* 시점에만 쓴다
   (진입 시 1, 이탈 시 0). 화면 끔/켬·잠금화면·앱 전환·홈·최근앱·알림창은 **전부 무해하다**
   ([12](12-trigger-matrix.md)). 게임을 안 하는 동안은 **우리 값을 덮을 주체가 없다.**
3. **전환에 20초쯤 걸린다.** pt=1 직후 첫 10~20초는 전류가 튄다.
4. 온도도 내려간다 (고부하 충전 32.2℃ 상승 vs 바이패스 31.8℃ 안정).
5. **전제조건**: PD/PPS 고속 충전 협상, **배터리 20% 이상 (실측 확인)**.
   20% 미만에서는 설정값이 1이어도 펌웨어가 무시하고 정상 충전한다 — 안전장치가 내장된 셈.

## 목적과 인정된 한계

목표는 **배터리 수명을 조금이라도 늘리는 것**이지, 충전을 완벽히 차단하는 게 아니다.
사용자가 아래 한계를 사전에 인지하고 수용했다:

- **완전 바이패스가 아닐 수 있다.** 실측 반론대로 30~70mA가 계속 흐르더라도 상관없다.
  만충 근처에서 계속 트리클 충전되는 것보다 나으면 된다.
- **PPS 25W+ 충전기, 배터리 20% 이상** 같은 펌웨어 강제 조건은 우회 대상이 아니다. 그냥 지킨다.
- 공식 지원 기능이 아니므로 **One UI 업데이트로 언제든 막힐 수 있다.**
- 효과가 정량적으로 얼마나 되는지는 아무도 측정한 적이 없다. **"없는 것보단 낫다" 수준을 노린다.**

따라서 이 프로젝트의 성공 기준은 "충전 전류 0 달성"이 아니라
**"게임이 아닐 때도 이 기능이 켜져 있게 만든다"** 이다.
프로젝트화할 경우 이 문단을 그대로 고지 문구로 쓴다.
